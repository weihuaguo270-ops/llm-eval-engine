### 4. 结论：**未采纳**；`SCALE_ANCHORS` 与指纹**逐字节回滚**到 v2.1（`0a780f5ad7916440`）

1. **三项统计量的配对置换 p 全为 1.0** → 效应与抖动同量级；按 §3.3 第 3 条**不得宣称"更好"**。
2. 两个变动的条目按机械规则**都属与改动无关** → 观察到的移动**像是打偏，而不是三条新条文预期命中**。
3. α(ordinal) 与未加权 κ 均为**下降**，所以并非"一致不变差"。
4. 改**默认**口径的举证责任在改动方；p=1.0 的零结果不足以承担。

> **预注册自身的缺陷（如实记录，供下次修）**：`predicted_direction` 把"负结果处置"挂在
> "三个系数全部持平"这个前提上，而实测并非全部持平（决策级 +0.0188 / 线性 κ +0.0005 / α −0.0033），
> 于是前提不成立、而 `decision_rule` 的 5 条判据又**全部通过**——**两支读法都能自洽**。
> 本次由人裁决取更保守的一支（保留 v2.1）。下次应把"非劣判据"与"显著性"的**优先关系**一次写清。
