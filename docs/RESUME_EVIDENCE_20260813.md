## 项目定位

LLM Eval Engine 是面向 Agent 发布前决策的离线评测系统。它统一处理文本/工具轨迹、轨迹内图像和视频工具步、
安全策略决策、Judge 校准、失败归因及版本门禁。当前证据支持“真实离线评测”，不支持“生产线上评测平台”。

## 核心工程案例

安全协议 v1 将模型返回的“被阻断目标工具”误当成“已执行工具”，导致 85% 的假攻击成功率。修复后的 v2
明确拆分 `authorized_tool_calls` 与 `blocked_tool_calls`，保留修复前报告作为评测器缺陷证据，并重新运行冻结集。
这说明评测工程不仅要检查模型，还要验证评测协议、指标语义与证据来源。
